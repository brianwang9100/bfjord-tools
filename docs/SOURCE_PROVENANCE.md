# Source provenance and export boundary

The Unity package consists of the original authoring implementation, its JSON samples, shaders and Editor tests. Its internal Bwork namespaces are retained. A repository audit of the 13 Core C# files and shaders found no copied third-party implementation or vendor copyright header; the source documentation identifies the road fitting, junction conformance and projected triangle math as original work. References to Clipper2, LibTessDotNet and other projects are research links, not vendored implementations.

The public export is an explicit whitelist: `Unity/WorldAuthoringTools` maps to `Packages/com.bfjord.tools`; the coastal bridge and original rock generators map to `scripts/coastal_bridge` and `scripts/rocks`; renderer-manifest dependencies, reviewed texture inputs and the bounded demo snapshot map to `assets/CoastalBridgeTool`; the rock manifest admits exactly six families, 24 FBXs and four shared maps under `assets/BFjordTools/Rocks`; top-level original water generators, documentation and provenance manifests map to `assets/BFjordTools/Water`; accepted Unity scene images and labeled Blender rock reviews map to `docs/images`. The private application's source, Git history, databases, settings, diagnostics, full Assets trees and research logs are excluded.

The 0.6 Terrain adapter verifies the installed URP 17.6 package and generates narrowly adapted shader files locally. Those derived files retain Unity's Companion License and provenance notice; Unity source is not claimed as original MIT implementation. The original stochastic sampling include and adapter are part of the toolkit. No source from the researched third-party stochastic-texturing projects is copied.

The additive oak B and birch B meshes are original Blender geometry. Public CC0 Poly Haven Bark Brown 02 maps supply only the oak bark island; source URLs and hashes remain in the woodland source receipt. The original leaf and birch-bark fields have no image inputs. New FBX exports use a clean material slot, with texture binding handled by Unity, so they contain no absolute texture URLs. The original A identities and existing prefab generations remain available.

The water maps are original deterministic mathematical fields with no image inputs. Their public `manifest.json` and `motion-manifest.json` record the package PNG dimensions, channel meanings and hashes without duplicating those package textures under the source bundle. `MOTION.md` records the Unity water sample and third-party projects considered as references; no reference source or asset is redistributed.

FBX metadata is parsed as typed, length-delimited properties. Private absolute source paths are replaced with relative texture/source basenames; node property lengths and offsets are regenerated. Every source first round-trips exactly, every output is reparsed, and all non-string properties remain byte-identical. Public snapshot manifests are computed from the transformed bytes and do not claim that a sanitized FBX retains its private-source hash. Editable Blender files are omitted because binary authoring state can retain private machine paths.

The rock geometry is original deterministic work, informed by public geology and Blender documentation rather than third-party mesh or generator code. The production references include [NPS rockfall guidance](https://www.nps.gov/yose/learn/nature/rockfall.htm), [USGS research on fluvial gravel roundness](https://pubs.usgs.gov/publication/70031076), Blender's [Displace](https://docs.blender.org/manual/en/5.0/modeling/modifiers/deform/displace.html), [Remeshing](https://docs.blender.org/manual/en/dev/modeling/meshes/retopology.html), [Decimate](https://docs.blender.org/manual/en/5.2/modeling/modifiers/generate/decimate.html), and [baking](https://docs.blender.org/manual/en/5.0/render/cycles/baking.html) documentation. ambientCG [Rock030](https://ambientcg.com/view?id=Rock030) supplies CC0 procedural color and normal images under the [ambientCG license](https://docs.ambientcg.com/license/); it does not supply the original geometry. NatureManufacture pages are visual/workflow references only, and no vendor bytes are included.

The exporter tracks only its own destination files. It compares prior exported hashes before replacing or removing a file and aborts on local modifications. Unowned destination files and Git metadata are preserved. Exporting does not initialize a Git repository, configure a remote or publish anything.
