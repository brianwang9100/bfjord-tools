# Coastal bridge demo bedrock

Tileable ambientCG Rock030 base color and OpenGL normal, 2K JPEG. CC0-1.0, ambientCG / Lennart Demes. Official source https://ambientcg.com/view?id=Rock030 and license https://docs.ambientcg.com/license/. Source method: procedural. Exact original download hashes are in Rock030.provenance.json; the raw archive remains in local artifacts. Only the color and normal listed here are replay dependencies.

These repeatable maps belong on terrain. Poly Haven rock_moss_set_01 is a scanned mesh UV atlas and must remain attached to its original mesh UVs; its unused black area must never be tiled across terrain.
